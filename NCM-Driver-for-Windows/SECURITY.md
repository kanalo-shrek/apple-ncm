# Security

This project is based on the [Microsoft Network-Adapter-Class-Extension sample](https://github.com/Microsoft/Network-Adapter-Class-Extension).

For security-related issues, please refer to Microsoft's official security documentation and reporting procedures:

- [Microsoft Security Response Center (MSRC)](https://aka.ms/opensource/security/msrc)
- [Report a security vulnerability](https://aka.ms/opensource/security/create-report)
- [Microsoft's definition of security vulnerabilities](https://aka.ms/opensource/security/definition)
- [Microsoft Bug Bounty Program](https://aka.ms/opensource/security/bounty)
